# Phase 3 成果物 — alternatives（代替案と却下理由）

> 正本: [`../../_shared-context.md`](../../_shared-context.md) §0（確定したデザイン決定）。

## 決定対象

見出し上の英語 overline（eyebrow）6 箇所（`CHAPTER SITE` / `FEATURED MEMBERS` / `ABOUT` / `THREE ZONES` / `RECENT MEETINGS` / `FOR MEMBERS`）の扱い。各 overline の直下には日本語見出しがある。

## 検討した代替案

### 案 A — 英語 overline を「翻訳して残す」

- 内容: `ABOUT → 概要`、`THREE ZONES → 3つの区画`、`FOR MEMBERS → メンバーの皆様へ` のように overline 要素を残したまま日本語へ翻訳する。
- 利点: DOM 構造変化が最小（テキスト置換のみ）。CSS 変更不要。
- **却下理由**: overline と直下の日本語見出しの**意味が重複**し、情報密度が上がるだけで「直感的にわかる」要求に弱い。例: `概要` overline の直下に「事業支援コミュニティ「UBM」」見出しが続くと二重ラベルになる。ユーザーは「最もすっきりする」削除案を選択した。

### 案 B — 「装飾スタイル（overline 体裁）を維持したまま翻訳」

- 内容: letter-spacing・小型大文字などの overline 装飾を保ったまま日本語化する。
- 利点: 既存のビジュアルリズムを保てる。
- **却下理由**: 装飾を強める方向であり、ユーザーが明示した「ホバーでブーンと開く等のギミックは不要・直感的にわかる仕組み」という意図に逆行する。重複ラベル問題（案 A と同様）も解消しない。

## 採用案 — overline 要素を削除

- 内容: eyebrow 要素を削除し、直下の日本語見出しのみにする。Hero は prop 非伝播（汎用性保持）、他は要素削除。dead CSS は同サイクルで削除。
- 採用経緯: **AskUserQuestion 2026-06-11**。提示した複数選択肢のうち、ユーザーが「見出し上の英語 overline は削除し、直下の日本語見出しのみにする（重複解消・最もすっきり）」を選択（SSOT §0 デザイン決定 1）。
- 利点: 重複解消・視認情報の単純化・装飾追加なし（ギミック不要の意図と整合）。

## 却下案との対照まとめ
