## 3.2 因果ループ

- 強化ループ: 説明導線追加 → 管理者が目的を理解 → 正しく対応づけ → 会員データ反映成功 → 画面への信頼向上 → 運用継続。
- バランスループ: 説明過多 → 圧迫感/ノイズ → 理解低下。→ 「コンパクトカード・常時表示」（AskUser 確定）で抑制。

## 3.3 論点チェック

1. 真の論点: 機能ではなく **情報設計・用語の伝達**（裏取り済み・RC-1..5）。
2. 依存・責務境界: `schemaGlossary` を単一正本に。`page.tsx` はセクション非競合。SchemaDiffPanel はロジック不変・表示追加のみ。
3. 価値とコストの不均衡: 高価値（理解回復）・低コスト（表現層）。フルウィザードは高コストのため OOS。
4. 改善優先順位: ①目的説明バナー（最重要）→ ②用語言い換え → ③操作アウトカム → ④統計/履歴文脈化。
5. 4条件: §3.1 全 PASS。
