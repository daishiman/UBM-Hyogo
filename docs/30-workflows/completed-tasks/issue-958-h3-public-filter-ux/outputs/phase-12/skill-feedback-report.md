# Skill Feedback Report

## Template Improvements

- A spec-created implementation workflow must state `implementation_pending` explicitly when no app code has been changed.
- If app code is added later in the same branch, root/output artifacts, Phase 12 docs, aiworkflow ledgers, and implementation paths must be reclassified to `implemented_local_runtime_pending` in the same cycle.
- Phase 11 VISUAL evidence planned paths must use `pending` until screenshots exist.

## Workflow Improvements

- For small implementation follow-up specs, root/output artifacts parity and Phase 12 strict 7 should be materialized in the creation wave.
- aiworkflow-requirements synchronization should include active workflow, quick-reference, resource-map, artifact inventory, changelog, and LOGS.

## Documentation Improvements

- The phrase "strict 7 outputs" should not imply runtime or implementation PASS. The status must identify whether the strict outputs are planning evidence or execution evidence.
