# Phase 11 — 手動テストチェックリスト（Apple HIG 観点）

> ステータス: `runtime_pending`（capture user-gated）。本チェックリストは認証済み visual capture 時に [x] を埋める。各項目は監査ログ `/admin/audit` の日本語化 + フィルタ段階開示 + カード整列結果に対する HIG 観点の評価。

---

## 1. 視覚的階層（Visual Hierarchy）

- [ ] フィルタフォームで「常時表示（よく使う 5 項目）」が前面、「詳細な絞り込み」が引き出し（`<details>`）として弱いウェイトで配置される（AC-2）
- [ ] 監査ログカードのタイムラインが目的・用語ガイドより主役として認識できる
- [ ] 見出し階層・ゾーン区切りが論理的で、初見でも「何を絞り込めるか」が伝わる（AC-1 / AC-2）

## 2. 焦点（Focal Point）

- [ ] よく使う絞り込み（操作の種類 / 実行者 / 期間 / 表示件数）が一目で見つかる（AC-1 / AC-2）
- [ ] 監査ログカードの「操作（日本語）」が各行の焦点として読み取れる（AC-3）
- [ ] 「いつ・誰が・何を操作したか」が一目で伝わる

## 3. 余白リズム（Spacing Rhythm）

- [ ] 適用フィルタチップ行 `.chip-row` が `gap: var(--ubm-space-2)` で均一に並ぶ（AC-7）
- [ ] 用語集グリッド・カード meta グリッドの間隔が `--ubm-space-*`（4px grid）に整合する（AC-7）
- [ ] 過密 / 過疎がなく、各ブロックが視覚的に「区切られている」と認識できる

## 4. タイポスケール（Type Scale）

- [ ] ラベル・値・補助テキストが `--ubm-text-*` のスケール段階に沿っている
- [ ] フォームラベル・カードラベル・チップラベルが日本語で表示され、英語キー名が露出しない（AC-1 / AC-3 / AC-4 / AC-5）

## 5. コントラスト（Contrast）

- [ ] 本文テキストと背景のコントラストが WCAG 2 AA（4.5:1）を満たす（AC-11）
- [ ] チップ・details の summary が背景に対して十分判読可能
- [ ] 全色が OKLch トークン（`var(--ubm-color-*)`）由来で、HEX 直書きが 0 件（AC-8）

## 6. タップ / クリック領域（Hit Target）

- [ ] `<summary>詳細な絞り込み</summary>` のタップ領域が十分（モバイルで誤タップしない）（AC-2 / AC-7）
- [ ] 検索 / リセット / ページネーション（cursor）のクリック領域が温存されている（AC-12）
- [ ] フォーカスリングがキーボード操作で保持される（`<details>`/`<summary>` / `FormField`）（AC-11）

## 7. 一目での理解しやすさ（Glanceability）

- [ ] 初期表示で詳細な絞り込みが閉じており、よく使う絞り込みだけで初見負荷が下がる（AC-2）
- [ ] 詳細フィルタ（targetType / targetId / batchId）に値があるときは `<details>` が自動展開され、適用中の条件が隠れない（AC-2）
- [ ] 監査ログカードの操作・対象種別が日本語で、生コードを読まずに把握できる（AC-3）

## 8. レスポンシブ（Responsive）

- [ ] desktop でフィルタ2層・カード・適用チップが整列して成立（AC-7）
- [ ] mobile でフォーム2層とカードが 1 カラム縦積みになり、横溢れ・レイアウト崩れがない（AC-7）

## 9. 既存機能温存（Regression Guard）

- [ ] 検索が挙動不変（`<input name>` = query param キーが英語維持）（AC-9 / AC-12）
- [ ] リセットが挙動不変（AC-12）
- [ ] ページネーション（cursor）が挙動不変（AC-12）
- [ ] PII マスク / JSON 開示が挙動不変（AC-12）
- [ ] エラー親切メッセージが温存（AC-12）
- [ ] 適用フィルタ `aria-label="現在の絞り込み条件"` が維持される（AC-11）
